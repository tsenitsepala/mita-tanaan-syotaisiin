# Mitä tänään syötäisiin?

Web-sovellus, joka auttaa ruokaidean keksimisessä silloin, kun päätöksenteko on vaikeaa.

## Ominaisuudet
- Reseptien arvonta eri fiilisten mukaan
- Inspiraationäkymä satunnaisista resepteistä
- Käyttäjän arvontahistoria (localStorage)
- Responsiivinen ulkoasu

## Käytetyt teknologiat
- HTML
- CSS
- JavaScript
- TheMealDB API
- LocalStorage

## Käyttö
Avaa index.html selaimessa ja valitse fiilis.
